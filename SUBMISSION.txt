Title
VersionMerge - Author-attested semantic merging

Notes / Description
Built VersionMerge, a reusable GenLayer Intelligent Contract for author-attested three-way section merging. The owner records a common base and two distinct author wallets; each author submits their own immutable version. Validators classify aligned section relationships, deterministic code performs non-conflicting merges and records explicit conflict choices, and both authors must approve every final result before it is sealed. GenVM lint and strict type checking pass; 14 direct security tests and a five-validator integration flow pass. A fresh StudioNet run proved separate author submissions, relations [1,2], bilateral approvals, SEALED state, and exact deployed-source equality.
